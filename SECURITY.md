# Security policy

This library handles sign-in, so we take reports seriously.

## Reporting a vulnerability

Please **don't open a public issue.** Report it privately through GitHub: go to this repository's
**Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and the version affected. We aim to acknowledge reports
within 3 working days and to release a fix for confirmed issues as quickly as their severity
warrants.

## Supported versions

Fixes go into the latest release. Before 1.0, that's the latest `0.x` minor version.
